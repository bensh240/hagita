# חגיתה - סודות של אוכל

Premium dark landing page for Hagita's cooking workshops.

**Live:** https://hagita.vercel.app

## Tech Stack

- React 19 + TypeScript + Vite
- GSAP + ScrollTrigger (scroll animations, horizontal gallery, parallax)
- Lenis (smooth scroll)
- Motion (Framer Motion)
- Tailwind CSS v4 + shadcn/ui

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx vercel deploy --prod ./dist
```
