Site uses dark theme (#0a0a0a) with warm gold accent (#c8956c). No cream/light backgrounds — user rejected them as "amateurish". 

**Why:** User benchmarks against Israeli agency sites (scpg.tv, bluebird-uav.com, cqisense.com). Anything that looks "template-like" or "junior-built" gets rejected.

**How to apply:** Always use dark backgrounds, minimal color palette (dark + white + gold accent), large bold typography, GSAP scroll animations, grain texture overlay. No colorful badges, no light sections, no basic card layouts.
